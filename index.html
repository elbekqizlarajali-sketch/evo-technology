⌨️ Dasturlash bilimlari

Dasturlash — kompyuterga muayyan vazifalarni bajarish uchun buyruqlar yozish jarayonidir.

HTML

HTML — veb-sahifaning tuzilishini yaratish uchun ishlatiladigan belgilash tilidir. Sarlavha, matn, rasm va havolalar HTML yordamida joylashtiriladi. 

<h1>Salom dunyo!</h1>
<p>Mening saytim</p>

CSS

CSS saytning tashqi ko‘rinishini bezaydi. Ranglar, shriftlar, joylashuv va animatsiyalar CSS orqali boshqariladi. 

h1 {
  color: blue;
  font-size: 30px;
}

JavaScript

JavaScript veb-saytga interaktivlik qo‘shadi. Tugmalar, hisoblagichlar, o‘yinlar va dinamik funksiyalar yaratishda foydalaniladi. 

let son = 10;
console.log(son);

Python

Python — sodda sintaksisga ega dasturlash tili. U sun'iy intellekt, ma'lumotlar tahlili va avtomatlashtirishda qo‘llanadi. 

print("Salom, dunyo!")

🚀 Innovatsiyalar olami

Innovatsiya — yangi g‘oya, usul yoki texnologiyani yaratish va amaliyotga joriy etishdir.

Sun'iy intellekt (AI)

Sun'iy intellekt kompyuterlarga ma'lumotlarni tahlil qilish, matn bilan ishlash va ayrim vazifalarni bajarishga yordam beradigan texnologiyalar majmuasidir.

Robototexnika

Robototexnika robotlarni loyihalash, yaratish va boshqarishni o‘rganadi. Robotlar ishlab chiqarish, tibbiyot va tadqiqotlarda ishlatiladi.

Kosmik texnologiyalar

Sun'iy yo‘ldoshlar, kosmik apparatlar va teleskoplar orqali olamni o‘rganish, aloqa va navigatsiya xizmatlarini rivojlantirish mumkin.

🖥 Kompyuter haqida bilimlar

Kompyuter — ma'lumotlarni qabul qilish, qayta ishlash, saqlash va natijalarni chiqarish uchun mo‘ljallangan elektron qurilma.

Protsessor (CPU)

Protsessor kompyuter buyruqlarini bajaradi va hisob-kitoblarni amalga oshiradi. Uning ishlash tezligi va yadrolari kompyuter unumdorligiga ta'sir qiladi.

Operativ xotira (RAM)

RAM dasturlar ishlayotgan paytda kerak bo‘ladigan ma'lumotlarni vaqtincha saqlaydi. Kompyuter o‘chirilganda undagi ma'lumotlar saqlanib qolmaydi.

SSD va HDD

SSD va HDD ma'lumotlarni uzoq muddat saqlash qurilmalaridir. SSD odatda tezroq, HDD esa ko‘pincha katta hajmli saqlash uchun qulay bo‘ladi.

Videokarta (GPU)

GPU grafik tasvirlarni qayta ishlaydi. U o‘yinlar, video montaj va ilmiy hisoblashlarda muhim ahamiyatga ega.
